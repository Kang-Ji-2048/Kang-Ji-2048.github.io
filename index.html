    Personal project · Feb 2025, ongoing · Public repository

    Formula 1 Data Pipeline

    The project I point at when someone asks whether I do things properly. Everything in it is public, so every claim on this page can be checked against the repository.

    The pipeline

    Batch and real-time ETL in Python, polling the OpenF1 and Ergast APIs into a normalised PostgreSQL schema. Every record passes Pydantic validation on the way in, and writes are idempotent upserts, so re-running the same window produces the same database. That property is what makes the live path safe to retry.

    Engineering

    GitHub Actions runs CI on every push: ruff, mypy --strict and pytest. The stack is containerised with Docker Compose and deployed on AWS using EC2 and S3, with an instance bootstrap script and a redeploy path in deploy/.

    The model

    A gradient-boosting points model trained on leakage-safe features only: qualifying grid position, rolling recent form, season-to-date and constructor form, and driver history at the circuit. Nothing from the race itself. Evaluation runs against a linear-regression baseline on a time-ordered split, reported as MAE and R², because a random split would let the model see the future.

    The dashboard

    A Streamlit and Plotly front end with nine views covering championship standings, pace, race strategy, telemetry traces and model predictions.

    UCL Innovation Fest · Jun 2026 · Cryptography and privacy engineering

    Amnesty International × Manifest

    Amnesty International APAC needed to prove that abuses happened at scale. The people who could prove it could not afford to be identified. No template existed for holding both of those at once, so the work was designing one.

    Proving membership without revealing it

    Zero-knowledge membership proofs using Semaphore, with nullifiers to guarantee one testimony per person without linking that testimony to an identity. BBS+ verifiable credentials handle selective disclosure, so a witness can prove one attribute of a credential without surrendering the rest. Secure multi-party computation aggregates counts across parties, meaning no single party ever holds the raw set.

    Publishing aggregates safely

    An aggregate statistic can still betray the individual behind it. Publication runs through differential privacy using the Laplace mechanism, then k-anonymity and cell suppression. Published figures carry Bitcoin-anchored tamper evidence via OpenTimestamps, so they can be shown to predate any later dispute.

    Threat model

    I built a static, backendless interface prototype for tiered disclosure, and modelled a Pegasus-class adversary explicitly: device seizure and internet shutdowns, with the trade-offs written down rather than assumed away.

    Research · May to Jun 2023 · Templeton Scholarship

    Templeton Scholarship Project

    A badminton court is a small search space with a hard constraint: you have to recover to somewhere useful before the next shot arrives. Self-directed research under a Templeton Scholarship, and the first time I chose the methods myself.

    Method

    Applied Ant Colony Optimisation, Simulated Annealing and the Concorde solver to model court movement, cutting distance travelled per point by 24% on average under Monte Carlo benchmarking.

    Extension

    Extending the models to adapt to opponent play styles reduced variance in efficiency gains by roughly 10%. The average mattered less than whether the gain held up against different opponents.
